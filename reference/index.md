# Package index

## Session information

- [`session_info()`](https://sessioninfo.r-lib.org/reference/session_info.md)
  : Print session information

## Advanced session information

- [`external_info()`](https://sessioninfo.r-lib.org/reference/external_info.md)
  : Information about related software
- [`package_info()`](https://sessioninfo.r-lib.org/reference/package_info.md)
  : Information about the currently loaded packages, or about a chosen
  set
- [`platform_info()`](https://sessioninfo.r-lib.org/reference/platform_info.md)
  : Information about the current platform
- [`python_info()`](https://sessioninfo.r-lib.org/reference/python_info.md)
  : Python configuration

## Comparing sessions

- [`session_diff()`](https://sessioninfo.r-lib.org/reference/session_diff.md)
  : Compare session information from two sources

## Utility functions

- [`os_name()`](https://sessioninfo.r-lib.org/reference/os_name.md) :
  Human readable name of the current operating system
